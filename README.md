# fo-meteo

Frontend Vue 3 + TypeScript pour visualiser les prévisions météo.

## Technologies

- Langage: TypeScript 5.x
- Framework: Vue 3.x
- Bundler / Dev Server: Vite
- Style: Tailwind CSS

## Quick Start

### Installer les dépendances

```bash
npm install
```

### Configurer les variables d’environnement

Copier le fichier .env.example en .env et adapter:

```bash
VITE_API_URL=http://localhost:8000
VITE_PORT=5173
```

### Lancer le serveur de développement

```bash
npm run dev
```

Le frontend sera disponible sur http://localhost:5173 par défaut (Vite)
